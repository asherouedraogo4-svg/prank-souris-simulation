# CTRL//FLIP — simulation pédagogique

Démo Web inoffensive d'une inversion temporaire des contrôles **dans une zone de la page uniquement**.

- Durée : 10 secondes
- Arrêt : bouton « Arrêter » ou touche Échap
- Aucun script système, aucune installation, aucun réglage Windows modifié
- Fonctionne directement dans un navigateur

## Lancer localement

Ouvrir `index.html` dans un navigateur.
